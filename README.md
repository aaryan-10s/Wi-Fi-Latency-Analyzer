# Wi-Fi-Latency-Analyzer
The project that I am currently developing: program a JAVA WEB application - a Wi-Fi Latency Analyzer project. The WEB application is designed to assist individuals, whom face latency/connectivity issues, like gamers and video-call users, to determine whether their connectivity issues are more likely caused by local Wi‑Fi/router instability or the wider internet path. Wi‑Fi Latency Analyzer is a Windows desktop app for users with a Windows computer and internet connection.
AI usage: ChatGPT was used as an assistant, teacher, and debugger throughout development. When I encountered unfamiliar concepts or syntax, such as ProcessBuilder and Java Swing, AI helped explain the concepts and syntax rather than simply providing finished code.
For the LatencyAnalyzerWindow.java desktop UI, AI was especially helpful in learning the Java Swing syntax and APIs. I focused on understanding the code before incorporating it into my project.
